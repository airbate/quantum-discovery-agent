# 数据来源与使用声明

## 当前演示数据

当前可提交仓库中的 `data/examples/demo_candidates.csv` 是为软件验收构造的合成反应条件数据，包含：

- 16 个候选条件；
- 类别特征：ligand、solvent、base；
- 数值特征：temperature、cost、risk、runtime_minutes；
- 目标列：yield；
- 任务配置：批次大小 3、成本上限 5。

该文件不来自真实实验，不代表化学事实、实验结果或安全结论，也不用于宣称模型具有真实科研效果。它的用途是稳定复现数据审计、代理模型、QUBO、量子模拟和独立验证链路。

## 正式数据替换要求

正式科研评测或答辩演示应替换为公开或已授权的数据，并在运行报告中填写：

| 字段 | 要求 |
| --- | --- |
| `dataset_id` | 数据集名称和版本 |
| 来源 URL/DOI | 可追溯地址 |
| 下载日期 | 数据快照获取日期 |
| 许可证 | 许可证名称和使用限制 |
| 快照哈希 | 文件 SHA-256 |
| 字段映射 | 原始字段到候选/观测模型的映射 |
| 脱敏/预处理 | 缺失、异常、重复和单位处理 |

候选数据可以来自公开高通量实验项目（例如 Open Reaction Database）或团队自有且已授权的数据。使用任何第三方数据前，应由团队自行完成许可证、隐私和领域合规审查。

## 结果解释边界

模型预测值不是实测值；Qiskit Aer 采样结果不是量子硬件结果；推荐批次需要领域专家审核并通过真实实验验证。任何真实数据接入后都必须保留输入快照、审计结果和可复现配置。
