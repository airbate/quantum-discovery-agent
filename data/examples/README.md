# 数据说明

`demo_candidates.csv` 是一个可复现的合成反应条件表，用于验证软件链路、约束、QUBO 和离线回放，不代表真实湿实验结果，也不用于宣称化学性能。

正式科研评测应替换为完成许可审查的公开高通量实验数据。优先适配 Open Reaction Database（ORD，开放数据项目）或团队自有且已授权的数据，并在 `dataset_id`、数据快照哈希和运行报告中记录来源、许可证、字段映射和下载日期。

适配真实数据时不需要修改 QUBO、求解器或 Agent 接口；只需实现新的数据加载器和领域特征 Adapter。系统默认不会把合成 demo 数据描述成公开实验数据。
